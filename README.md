# My Training

My own training app, using my Garmin data in Intervals.icu.

- **Today**: GO, EASY or REST each morning by my own rules (ring of the five rules, rule tiles, 7-day strip), with today's planned session.
- **Trends**: running mileage over 12 weeks (weekly bars, rolling 7-day line, trend) and the Garmin VO2max estimate (28 days or 12 weeks).
- Opens as an app on my phone (installed from Chrome). The API key is stored only on the phone.
- Rules, weekly plan and the mileage trend setting are editable in the app (⚙ Settings).

To update the app: replace `index.html` here (Add file → Upload files → Commit). The phone picks it up the next time it opens with signal (allow a few minutes for GitHub's cache).
